# Security

If you find a vulnerability in the 7ots desktop app, the CLI or the local server, please **don't open a public
issue**. Report it privately through GitHub's
[security advisory form](https://github.com/7ots/pet/security/advisories/new).

Please include what you found, how to reproduce it, and the version (`7ots status --json` or the app's About).
We'll confirm receipt within a few days and keep you posted until it's fixed.

Only the latest release is supported. The app updates itself, so most users get fixes within a day of a release.
